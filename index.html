CODING AGENT FOR THE TERMINAL

Hey Uno.

Uno reads your project, edits files and runs commands. It asks before it edits your files, runs shell commands in a sandbox, can undo every file change, and stops at a hard spending cap. It starts in milliseconds and is about 3 MB. It is young and does not do everything yet, so here is where it stands.

curl -fsSL https://unocode.motiontic.com/install.sh | sh
brew install motiontic/tap/uno
npm i -g @motiontic/uno

macOS and Linux, arm64 and x86_64. Then run uno in a project folder. New here? Read the quickstart or browse the docs.

01

ASKS FIRST

File edits wait for your say-so, unless a rule or mode allows them. Shell commands run inside the sandbox; one that needs to leave it asks.

02

SANDBOXED

Shell commands cannot write outside the project, read your secrets or reach the network.

03

UNDOABLE

Every file change is recorded, so uno undo puts it back.

04

CAPPED

Spending on model calls stops at a cap you set, $5.00 unless you change it.

01 Why Uno

Uno is a small coding agent, built from scratch by a small team. It does much of what Claude Code and Codex do, and several of its best ideas came from studying them. Where it differs is size and cost. Here is where it stands, including the parts that are not there yet.

MeasureUnoClaude Code
Downloadabout 3 MB217 MB
Memory while it waits for youabout 3 MBabout 180 MB
Instructions sent with every requestabout 3,500 tokensabout 46,000 tokens

That last row matters most for your bill: every request carries those standing instructions, and you pay for them each time. On ten practice coding exercises, with the same model (Claude Haiku 4.5) and one try each:

Ten exercisesUnoClaude Code
Solved10 of 1010 of 10
Cost$0.35$1.11
Timeabout 4 minutesabout 12 minutes

What this does not show:

  • Ten small exercises is a small test. It cannot tell the two apart on harder, longer work. We ran it ourselves on 30 September 2026, before the browser, long-term memory and helper agents arrived. We will run it again and publish the result, even if the gap shrinks.
  • Uno is not smarter. The model does the thinking. Give Uno and another agent the same model and expect the same quality of work.
  • We have not measured Codex yet. Every figure here is against Claude Code.
  • Still to come: Windows, a to-do list Uno keeps while it works, asking you a question when it is unsure, scheduled runs, and streamed JSON output for scripts.
